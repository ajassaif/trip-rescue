# Demonstration

The completed [video](demo/README.md) is 2 minutes 28 seconds, with captions and a [transcript](demo/transcript.md). It is a silent, edited walkthrough of the actual 18 October AWS responses. Result panels are rendered from saved JSON, not newly executed model calls. The introduction uses an earlier offline-demo UI screenshot, labeled accordingly.

Sequence: recovery problem → agent architecture → transport → stays → disruption reports → actual low-confidence abstention → reusable pattern and evidence.

The distinction between the model candidate (`find_transport`, 0.5905) and the application action (`clarify`) is retained. No accuracy, calibration, latency-saving or real travel-availability claim is made.
